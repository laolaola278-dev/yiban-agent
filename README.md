# 易班百事通

> 有问必答，答必有据 —— 面向校园事务的智能问答助手

一个基于 **RAG（检索增强生成）** 的校园事务智能体：把学校官网公开发布的 64 篇真实校规变成可对话的知识库，学生用一句话提问，系统从原文检索作答，**每条回答附出处**，查不到就明说并给出官方渠道，绝不编造。

参赛项目：2026 广东省「数智新技艺」作品遴选 · 作品类型：智能体应用

## 核心能力

- **答得出**：覆盖奖助学金、综测、宿舍报修、报销四类事务，64 篇真实校规入库
- **答得对**：条款级切片 + bge-m3 向量检索 + 可选二阶段精排，回答标注来源文件与章节
- **会办事**：意图路由四分支 —— 政策问答 / 多轮澄清 / 校历查询 / 材料清单生成
- **不忽悠**：检索置信度阈值 + NOT_FOUND 检测 + 兜底引导，杜绝模型编造

## 知识库

| 条线 | 篇数 | 代表内容 |
|---|---:|---|
| 资助 | 13 | 国家奖学金/励志/助学金评审办法、困难认定、勤工助学 |
| 学生管理 | 14 | 学生奖励办法(2026修订)、处分管理规定、晨午晚检 |
| 宿舍 | 18 | 学生公寓管理规定(全文)、报修 8 步流程、水电费标准 |

全部来自广东职业技术学院官网公开发布，每篇附来源 URL 登记（`manifest.jsonl`）。

## 快速开始

```bash
# 1. 配置 API Key（DeepSeek 对话 + SiliconFlow 向量，bge-m3 免费）
cp .env.example .env      # Windows: copy .env.example .env

# 2. 一键启动（Windows 双击 启动.bat）
docker compose up -d --build

# 3. 访问 http://localhost:7860，登录 admin / admin
```

也可原生运行：双击 `启动.bat`（自动建环境→装依赖→建知识库→起服务→开浏览器）。

## 工具箱

| 脚本 | 用途 |
|---|---|
| `启动.bat` | 一键全栈：环境 + 建库 + 后端 + 前端 |
| `停止.bat` | 停止全部服务 |
| `启动-docker.bat` | Docker 一键部署 |
| `重建知识库.bat` | 更新校规文件后重新索引 |
| `跑评测.bat` | 批量评测出通过率与响应时间 |

## 可选增强

- 二阶段精排：`.env` 设 `USE_RERANK=1` 并装 `requirements-optional.txt`，FAISS 召回 20 → bge-reranker 精排 5
- RAG 评测：`python scripts/eval_ragas.py` 出忠实度/相关性/精确率/召回率四维指标
- 答辩附录：把现场问答 + 引用导出成 PPTX
