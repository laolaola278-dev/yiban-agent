## 失败/受限项

- `www.docer.com` 跳转到 `docer.wps.cn`；`docer.wps.cn/ppt` 返回 404，首页标题为“会员免费下载”，未纳入主清单。
- `slidesgo.com/freetemplates` 与 `?category=technology` 在抓取时返回 404 壳页，未纳入主清单。
- `officeplus.cn/template`、`officeplus.cn/Template/Home/Ppt` 返回 404；首页可访问，因此只收录官网首页入口。
- `raw.githubusercontent.com` 在本机直连间歇失败；GitHub 文件路径由 GitHub Tree/Contents API 核实，raw 直链可直接复制下载。
- `Anthony0630/Defense-PPT-Template` 与 `doubleZ0108/TJ-Graduation-Project-2021` 的 GitHub API 未给出 LICENSE，作为高校答辩备选而非首选。
- Microsoft 与 Slidesgo 类站点缩略图为 webp；本目录优先保留 jpg/png 预览，webp 仅在能落盘时随附。
