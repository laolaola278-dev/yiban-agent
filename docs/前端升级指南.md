# 前端升级指南：给自研 RAG 换"高颜值皮肤"

后端已提供 OpenAI 兼容接口（backend_api.py，端口 8010），以下任意前端都能直接接入，**自研检索/引用逻辑零改动**。

## 方案 A：open-webui（推荐，答辩最稳）

    :: 后端（本项目）
    启动后端.bat          → http://127.0.0.1:8010/v1

    :: 前端（新开一个命令行）
    pip install open-webui
    open-webui serve      → http://127.0.0.1:8080

配置三步：
1. 首次打开 8080 注册本地管理员账号（纯本地，不联网）
2. 右上角设置 → 管理员面板 → 外部连接 → OpenAI API
3. 填 URL：http://127.0.0.1:8010/v1，Key 随便填（如 sk-local）→ 保存 → 顶部选模型 yiban-agent 开聊

加分细节：把助手名称改成"易班百事通"、头像换成校徽（管理员面板 → 模型编辑）。

## 方案 B：kotaemon（引用 UI 最强）

    pip install kotaemon
    khem serve 或 python -m kotaemon.app

进入设置页选 "OpenAI Compatible" → 填 http://127.0.0.1:8010/v1。
优势：引用以行内角标+侧边文档面板呈现，"答必有据"视觉冲击最强；代价是 Gradio 风格界面、首次配置略繁琐。

## 方案 C：lobe-chat（颜值天花板）

    docker run -d -p 3210:3210 lobehub/lobe-chat

设置 → 语言模型 → OpenAI → API 代理地址填 http://host.docker.internal:8010/v1，Key 任意。
界面最精致，但引用来源展示弱，需要回答文本里自带引用块（后端已实现）。

## 现场部署建议（答辩）

- 演示机提前装好方案 A，双开窗口：后端 bat + open-webui
- 手机热点保证浏览器与后端同机（本机演示无网络依赖，仅模型 API 需联网）
- PPT 架构图加一行：自定义 OpenAI 兼容网关（backend_api.py）—— 体现工程化能力
